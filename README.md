## Key Features

Concrete Scenario

In a manufacturing setting, a production manager uses Jev to analyze the reliability of a new material for a specific product. The manager inputs the material's properties, such as its melting point and thermal conductivity, into the system. Jev then outputs a probability distribution over the possible choices for using the material in the production process. The manager can then review these probabilities to determine the most likely outcome and make an informed decision about whether to proceed with the material. This allows the production manager to balance the benefits of using the material with the potential risks and limitations.

## Use Cases

Capability

Jev allows users to specify multiple scenarios or constraints, which can be used to generate probability distributions over different outcomes. This can be particularly useful in situations where the outcome is not binary, such as in medical diagnosis where the probability of a patient having a certain disease can range from 0 to 1.
